# HP4G - HidePost4Guest
a phpBB extension:

Randomly obscure post in a topic to guest
Where it appears: inside posts and below topic title (if selected)
Administration: set up % to obscure randomly posts in topic (will obscure the % in a page...like 75% of the posts in a page), choose if display/not display the above alert, choose if display/not display the first post of the topic

Languages: en, it

The goal is to obscure part of topic, to get user registerd instead of reading entire topic without registering.
WARNING the obscuration is random, if you reload the page, others post will be displayed so the entire topic could be read. The purpose is to invite users to register, not to obscure the entire topic.
