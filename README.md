phpBB forum ext:
The extension provides an alternative to completely denying access to a forum.
If you want to display only a part of the topic, this is for you!

It allows you to set, through the administrator control panel:
Display of an alert message indicating that the content of the page is partially obscured.
The multiple selection of one or more forums to which apply the obscuration (requires read-only access for guests in the forum permissions).
Option to (always) hide/display the first post.
A percentage of hiding for posts in the topic.
Visitors are encouraged to register for full access to the content.
Bots are not affected to the hided messages.

If update from v.1.0.0 you have to uninstall and delete data

Language provided: en, it

WARNING: The obscuration is random. By refreshing the page, different posts may be obscured randomly. Therefore, continuously refreshing the page may eventually allow reading of the entire topic.
